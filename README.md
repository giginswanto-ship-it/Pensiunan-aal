# Lembar Data Alumni AAL (Tampilan HP Android)

Aplikasi Web Mobile **Lembar Data Alumni AAL** dirancang khusus dengan antarmuka (UI/UX) bergaya **Smartphone Android** (Material Design 3). Aplikasi ini siap pakai tanpa perlu instalasi server atau software tambahan, cukup buka file `index.html` langsung di browser HP Android maupun komputer/laptop.

---

## 📱 Fitur Utama & Bidang Data Sesuai Permintaan

Aplikasi ini mencakup seluruh data yang diminta dengan tampilan kartu profil yang rapi, elegan, dan profesional:

1. **Foto Alumni (Ukuran 3x Lebih Besar, Fitur Zoom & Simpan)**  
   - Tampilan foto utama kini **3x lebih besar** (336px x 336px) dengan sudut membulat modern & elegan.
   - **Fitur Zoom Interaktif**: Ketuk foto untuk membuka penampil layar penuh (Lightbox). Mendukung cubit layar (*pinch to zoom*), ketuk dua kali (*double-tap* untuk zoom 2x), tombol perbesar/perkecil, serta geser foto (*pan/drag*).
   - **Fitur Simpan / Download Foto**: Tombol **"Simpan Foto"** langsung di kartu profil dan di dalam jendela zoom untuk mengunduh foto ke galeri HP Android atau folder unduhan PC (format JPG).
   - Dukungan upload foto dari Galeri HP atau langsung jepret dengan Kamera HP.
   - Dilengkapi fallback avatar otomatis jika belum ada foto.
2. **Data Diri**:
   - **Nama Lengkap & Gelar**
   - **Tanggal Lahir** (Otomatis menampilkan format tanggal Indonesia dan kalkulasi perkiraan usia).
3. **Alamat Sekarang** (Alamat domisili saat ini).
4. **No WhatsApp**  
   - Dilengkapi tombol cepat **"Hubungi via WhatsApp"** yang langsung membuka obrolan WA ke alumni tersebut dengan template sapaan alumni.
5. **Devisi & Perusahaan (Detail Penempatan Lengkap & Terintegrasi 41 Entitas AAL)**:
   - **Database 41 Entitas Perusahaan AAL**: Terintegrasi lengkap dengan seluruh 41 anak perusahaan dan unit operasional PT Astra Agro Lestari Tbk sesuai dokumen resmi korporasi (Sumatra 8 PT, Kalimantan 20 PT, Sulawesi 7 PT, Hilirisasi/Jasa 5 PT, dan Holding Jakarta).
   - **Modal Katalog Direktori Perusahaan Interaktif**: Tombol *"Pilih dari 41 Entitas AAL"* membuka direktori visual dengan fitur pencarian instan dan filter wilayah (Semua, Sumatra, Kalimantan, Sulawesi, Hilirisasi, Holding). Cukup 1x ketuk kartu perusahaan, maka:
     - Nama Perusahaan terisi otomatis.
     - Penempatan otomatis terpilih (*Head Office* atau *Site*).
     - Nama Site terisi otomatis sesuai lokasi perkebunan / pabrik / kantor.
   - **Autosuggest Datalist Cepat**: Kolom input Nama PT dan Site PT dilengkapi rekomendasi cerdas otomatis saat mengetik nama PT atau nama daerah.
   - **Devisi Berapa**: Menampilkan nomor divisi spesifik (contoh: *Divisi 1*, *Divisi 2*, *Divisi 3*, *Divisi Pabrik Kelapa Sawit (PKS)*, dll.).
   - **Penempatan Kerja**:
     - **Head Office (HO)** (Kantor Pusat Pulo Gadung, Jakarta Timur)
     - **Site (Cantumkan Nama PT)** (contoh: *Site PT Sari Lembah Subur*, *Site PT Kimia Tirta Utama*, *Site PT Sukses Tani Nusasubur*, dll.).
6. **Rentang Waktu Bekerja di AAL** (Tahun Mulai s/d Tahun Selesai/Pensiun, serta kalkulasi otomatis masa pengabdian).
7. **Mantan Atasan Terakhir** (Nama atasan / Manager saat bertugas).
8. **Tahun Pensiun** (Tahun purna bakti alumni).
9. **Kegiatan Saat Ini** (Aktivitas atau profesi di masa purna bakti, seperti berkebun sawit mandiri, wiraswasta, konsultan perkebunan, atau menikmati waktu bersama keluarga).
10. **Informasi Cucu / Penerus Generasi**:
    - **Jumlah Cucu (Total)**: Total jumlah cucu keluarga alumni.
    - **Cucu Laki-laki**: Jumlah cucu berjenis kelamin laki-laki.
    - **Cucu Perempuan**: Jumlah cucu berjenis kelamin perempuan (otomatis menghitung total cucu saat diinput pada formulir).
11. **Tombol Share Link (Bagikan Lembar Data)**:
    - **Tombol Share Tunggal & Bersih**: Tombol *"Share"* praktis disematkan di header atas aplikasi (App Bar), tanpa duplikasi banner atau tombol yang memenuhi layar.
    - **Dukungan Native Web Share & Salin Otomatis**:
      - Membuka menu berbagi bawaan sistem (WhatsApp, Telegram, dll.) secara instan di HP Android / iOS tanpa duplikasi teks link.
      - Otomatis menyalin tautan ke clipboard disertai notifikasi toast jika diakses melalui browser desktop atau mode offline.
12. **Logo Resmi Astra Agro Lestari**:
    - Disematkan pada Header Atas Aplikasi, Kop Kartu ID Profil Alumni, Modal Formulir Pengisian, Penampil Zoom Foto, Favicon Tab Browser, dan Watermark Kartu.

## 🌟 Fitur Tambahan Pendukung

- **Desain Khusus Layar HP Android**: Menampilkan status bar Android, punch hole kamera, kartu profil modern, serta navigation bar.
- **Toggle Frame HP di Komputer**: Jika dibuka di PC/Laptop, terdapat simulator frame HP Android yang bisa di-toggle ke tampilan lebar.
- **Penyimpanan Lokal (LocalStorage)**: Data tersimpan di memori browser pengguna, sehingga tidak akan hilang saat halaman ditutup atau di-refresh.
- **Kelola Banyak Alumni (Direktori Warga)**: Bisa menambah warga baru, mencari nama/devisi/kota alumni, mengubah data, serta menghapus data.
- **Cetak / Simpan ke PDF**: Siap dicetak langsung dengan layout kartu biodata yang rapi dan bebas tombol navigasi saat di-print.

## 🚀 Cara Menggunakan

### Cara 1: Di Komputer / Laptop (Windows)
- Cukup **klik dua kali (double-click)** pada file `Buka_Lembar_Data_Alumni.bat` atau klik kanan `index.html` lalu pilih **Open With -> Google Chrome / Microsoft Edge**.

### Cara 2: Di HP Android Langsung
1. Salin/kirim file `index.html` ke HP Android Anda (melalui WhatsApp, Google Drive, kabel USB, atau email).
2. Di HP Android, buka File Manager / Pengelola File, cari file `index.html`, lalu ketuk dan buka dengan **Chrome** atau browser bawaan HP.
3. Halaman akan tampil **100% penuh layaknya aplikasi Android asli**!
